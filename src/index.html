    ⚖️ Balanced Mode
    Optimized for mid-range systems. Balances performance and features with moderate resource usage and reasonable update intervals.
    🚀 High-End Mode
    Enables all features and faster update intervals. Best for powerful systems with plenty of RAM and CPU cores.
